## 二、技术优化项

### 2.1 架构优化

| 优化项 | 当前问题 | 建议方案 | 优先级 |
|--------|---------|---------|--------|
| Milvus真实向量检索 | 关键词加权模拟 | 接入真实Milvus | P1 |

| 服务链路追踪 | 无 | 引入SkyWalking/Jaeger | P3 |

| 优化项 | 当前问题 | 建议方案 | 优先级 |

| 图片压缩 | 原始大小上传 | 前端压缩+CDN | P3 |
| 分页优化 | 全量查询 | 深度分页优化 | P3 |

### 2.3 代码质量
