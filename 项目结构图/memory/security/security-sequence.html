security 模块时序图

sequenceDiagram participant C as 客户端 participant GW as api-gateway participant Filter as JwtAuthFilter participant SC as SecurityContextHolder participant CTL as Controller C->>GW: GET /api/v1/memories
Authorization: Bearer <token> GW->>Filter: 转发请求 Note over Filter,SC: JWT 过滤器拦截（在表单认证之前） Filter->>Filter: 取 Header → 去 Bearer 前缀 → 解析 alt Token 有效 Filter->>SC: setAuthentication(userId, role) Note over SC: 票据存入 ThreadLocal else Token 无效 / 过期 Filter-->>C: 401 Unauthorized end Note over CTL,SC: 业务层获取当前用户 CTL->>SC: getAuthentication() SC-->>CTL: 当前用户身份 CTL-->>C: 200 OK + 响应体
