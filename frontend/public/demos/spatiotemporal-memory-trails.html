Atlas · v1.1

时空记忆流光已合入主应用

这份独立 HTML 原型已被替换为 Vue 单文件组件，现已成为系统的一部分。 新版本基于 MapLibre 5.5 的 projection: 'globe'，以彩色 OpenFreeMap Liberty 为底图， 接入真实记忆数据 + 跑马灯网格 + 五级下钻 + 双层动线。

  • 真实数据：通过 memoryStore.fetchList() 拉取登录用户的记忆。
  • 球形投影：地球边界，可自转，2D ↔ 3D 切换。
  • 更大的 UI：320–340px 面板、42px 按钮、13–16px 字号。
  • 多模态：本地素材库 + Minio 预留接口。
